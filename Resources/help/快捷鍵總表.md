# 快捷鍵總表

功能鍵已設成標準功能鍵，可以直接按 F1、F2 等按鍵。

- **F1**：開啟或關閉這個說明介面；也可以按 Esc 關閉
- **F2**：幫目前聊天室改名；焦點在終端機格時不作用
- **F3**：收起或打開左側欄
- **F4**：收起或打開右側欄
- **F5**：開關浮動終端機；焦點在瀏覽器格時改為重新載入網頁
- **F6**：開啟或關閉關聯圖面板
- **F7**：目前未分配
- **F8**：目前未分配
- **F9**：程式碼區的檢查
- **F10**：程式碼區的執行
- **F11**：macOS 顯示桌面，非 codenv 功能
- **F12**：開啟或關閉全部的用量面板

F12 會在顯示面板時重新查詢用量，不會把輸入焦點從原本的格子移走；關閉面板後，焦點回到原處。
